# API contracts

Every route the application serves, the permissions it requires, and what it is for.

Authorization is declared on the handler and enforced by a guard before the
handler runs. A route with no `@RequirePermissions` and no `@Public` is a
route nobody decided about, so they are listed separately below rather than
buried in the table.

Generated 2026-09-02 from the schema, the route table and the permission catalogue.

**361 routes across 31 areas.**

Every route is served twice: unversioned under `/api`, and under `/api/v1`.
A client that has been calling `/api/...` keeps working; a new integration
can pin `/api/v1/...`. A future `v2` is added per controller with
`@Version('2')`, and `v1` stays as it is until it is deliberately retired.
